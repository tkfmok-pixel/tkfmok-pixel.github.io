M2 Mac miniを**「最強のホームサーバー兼AIエージェント作業場」**にするための第一歩、Homebridgeのインストール手順を詳しく解説します。

画面がない「ヘッドレス運用」を想定し、メインのMacBook Air（MBA）から操作する流れで進めましょう。

---

### 手順0：準備（MacBook AirからMac miniを操作する）

1. **Mac miniの起動:** モニターとキーボードを一時的に繋ぎ、「システム設定」＞「一般」＞「共有」で**「画面共有」**をオンにします。
    
2. **MBAから接続:** MBAで「画面共有」アプリを開き、Mac miniのIPアドレスまたはコンピュータ名を入力してログインします。これ以降、モニターは外してOKです。
    

---

### 手順1：Node.jsのインストール

Homebridgeは「Node.js」というプログラム実行環境の上で動きます。

1. Mac miniのブラウザ（Safariなど）で [Node.js公式サイト](https://nodejs.org/) にアクセスします。
    
2. **「LTS（推奨版）」**を選択して、`.pkg`ファイルをダウンロードし、インストールします。
    
3. 「ターミナル」アプリを開き、以下のコマンドを入力してバージョンが表示されれば成功です。
    
    Bash
    
    ```
    node -v
    npm -v
    ```
    

---

### 手順2：Homebridge本体のインストール

次に、ターミナルを使ってHomebridgeをシステムに組み込みます。

1. ターミナルで以下のコマンドをコピー＆ペーストして実行します（パスワードを求められたらMacのログインパスワードを入力してください）。
    
    Bash
    
    ```
    sudo npm install -g --unsafe-perm homebridge homebridge-config-ui-x
    ```
    
2. インストールが終わったら、Homebridgeをサービスとして登録し、**Macの起動時に自動で立ち上がるよう**設定します。
    
    Bash
    
    ```
    sudo hb-service install --user `whoami`
    ```
    

---

### 手順3：管理画面（ダッシュボード）へのアクセス

ここからは、同じWi-Fiに繋がっている**MacBook AirやiPadのブラウザ**から操作できます。

1. MBAのブラウザで `http://<Mac_miniのIPアドレス>:8581` を開きます。
    
    - （例：`http://192.168.1.10:8581` など。Mac miniの共有設定画面で確認できます）
        
2. 初めてアクセスすると、アカウント作成画面が出るので、任意のユーザー名とパスワードを設定してログインします。
    
3. **QRコードが表示されたダッシュボード**が開けば成功です！
    

---

### 手順4：iPhone 16eへの登録（仕上げ）

1. iPhone 16eの**「ホーム」アプリ**を開きます。
    
2. 右上の「＋」ボタン ＞ 「アクセサリを追加」をタップ。
    
3. 先ほどMac miniのブラウザ画面に表示された**QRコード**をスキャンします。
    
4. 「未認証のアクセサリ」と警告が出ますが、「そのまま追加」を選択して進めます。
    

---
