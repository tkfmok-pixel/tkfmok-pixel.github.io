# TASK LOG
昨日のMTGで[集約しーと](https://docs.google.com/spreadsheets/d/18MeaXELsT1lYdzHPWij29GYUIhMosDk2l1yt3Sd3FWU/edit#gid=1222566787)の企画案件進捗管理は編集しないシートにしたいと話しましたが、そのあと備考欄を編集したいという話が出たので、やっぱりボタンを押したら案件一覧から転記されるようにGASを組んでおきました。  

- 「！企画案件取得！」というボタンを押すとlatest_案件一覧のシートで対応状況が「企画する」のものが企画案件進捗管理シートに転記される
- 転記後にlatest_案件一覧の対応状況が「企画案件」に上書きされる

という設定にしました。触ってみてご意見いただけるとありがたいです！

function data_transfer() {

const ss = SpreadsheetApp.getActiveSpreadsheet();

const original_sheet = ss.getSheetByName('latest_案件一覧');

const posted_sheet = ss.getSheetByName('企画案件進捗管理');

  

for (let i=3; i<=100; i++){

let status = original_sheet.getRange(i,2).getValue();

if (status == "企画する"){

  

let original_values = original_sheet.getRange(i,19,1,5).getValues();

let lastrow= posted_sheet.getLastRow()+1;

posted_sheet.getRange(lastrow,3,1,5).setValues(original_values);

posted_sheet.getRange(lastrow,13,1,22).insertCheckboxes('yes');

newvalue = "企画案件";

original_sheet.getRange(i,2,1,1).setValue(newvalue);

}

}

}
