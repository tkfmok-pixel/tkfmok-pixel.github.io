## 準備: ChatGPTにプロンプトでダイエット目標を設定

まずは、ChatGPTに私の状況とダイエットの目標を伝えます。今回、私は\*\*「AI栄養士」 **としてChatGPTに協力してもらうことにしました。具体的には、現在の体重や目標体重、期間などを** プロンプト\*\*で入力し、1週間分の食事プランを作ってもらいます。プロンプトの内容が大事なので、できるだけ詳細に要望を伝えました。以下が実際にChatGPTに送ったプロンプトの例です。

```
あなたは経験豊富な管理栄養士です。私は30歳女性、身長158cm、体重60kg、デスクワーク中心で運動は週に1回程度しかしていません。1週間で1kg体重を減らしたいと考えています。私のために、一日だいたい1500kcal程度で収まるようなバランスの良い食事プランを1週間分考えてください。朝食、昼食、夕食ごとに具体的なメニューとおおよそのカロリーも教えてください。可能であれば、手に入りやすい食材で簡単に作れるメニューだと嬉しいです。
```

このようにプロンプトを送信すると、ChatGPTはすぐに **1週間分の食事メニュー** を提案してくれました！各日の朝・昼・夜ごとのメニューと、そのおおよそのカロリーが丁寧にリストアップされています。例えば初日の提案メニューは次のような内容でした。

- 朝食: オートミールとバナナ、ヨーグルト（約350kcal）
- 昼食: 鶏むね肉のサラダ（野菜たっぷり、ドレッシング少なめ）（約450kcal）
- 夕食: 鮭の塩焼きと温野菜、玄米ご飯（約600kcal）

他の日も、和洋さまざまなメニューが並びました。野菜やたんぱく質をしっかり摂れて、全体的に低カロリーに抑えた内容です。また、どれも **スーパーで手に入る食材** ばかりなので、特別な食品を買う必要もありません。想像以上に現実的で美味しそうな献立に、私はこの時点で期待が高まりました。

カロリー計算や栄養バランスの調整まで、すべてAIが自動でやってくれるなんて夢のようです。献立を一から考えるのはダイエット初心者には大変ですが、ChatGPTのおかげでその手間が省けました。

計画を実行に移すにあたり、必要な食材も確認しておきます。そこでChatGPTに1週間分の献立に必要な **買い物リスト** を尋ねました。

```
今週の献立に必要な食材をすべてリストアップしてください。
```

するとChatGPTは、主要な食材をカテゴリーごとにリストアップしてくれました。例えば以下のような内容です。

- 肉・卵・大豆製品: 鶏むね肉、鮭、卵、木綿豆腐、ツナ缶、豚ヒレ肉 など
- 野菜: ブロッコリー、ほうれん草、にんじん、トマト、レタス、きゅうり、玉ねぎ、キャベツ など
- 果物: バナナ、りんご、季節のフルーツ（みかん等） など
- 炭水化物: オートミール、玄米、ご飯、全粒粉パン、さつまいも など
- 乳製品・その他: 無糖ヨーグルト、低脂肪牛乳、ナッツ、カレー粉、オリーブオイル、塩胡椒など基本調味料 など

このリストをもとにスーパーでまとめて買い出しを済ませました。見慣れた食材ばかりなので戸惑うこともありません。あらかじめ準備を整えたことで、「これなら1週間頑張れそう！」と気持ちも引き締まりました。

## 1日目: AI栄養士のメニューでダイエット開始

いよいよダイエット開始の1日目です。朝、体重計に乗ると **60.0kg** （スタート時点）を指していました。「よし、1週間後にはこの数字を減らすぞ！」と気合を入れてキッチンに立ちます。

実はこれまで何度か自己流のダイエットに挑戦しては挫折してきました。AIに頼るのは初めてなので半信半疑でしたが、新しい方法にワクワクしています。

ChatGPTから提案された朝食メニューは「オートミールとバナナ、ヨーグルト」。普段あまりオートミールを食べない私にとって新鮮なメニューです。作り方がわからなかったので、早速ChatGPTに調理法を尋ねてみました。

```
オートミールを美味しく食べるにはどう調理したらいいですか？初心者向けの簡単なレシピがあれば教えてください。
```

するとChatGPTは、オートミールに牛乳を注いで電子レンジで温め、バナナのスライスとヨーグルトを添える簡単レシピを教えてくれました。さらに\*\*「シナモンを振ると風味が増しますよ」\*\*というようなアドバイスまで！言われたとおりに作ってみると、ほんのり甘くて満足感のある朝食が完成。これで約350kcalとは驚きです。久しぶりに朝食をしっかり食べたおかげか、午前中から体がシャキッと目覚め、仕事の集中力もいつも以上でした。

昼食は「鶏むね肉のサラダ」です。昨晩のうちに茹でておいた鶏むね肉と、レタス・トマト・きゅうりなどの野菜をたっぷりお皿に盛り付けました。ドレッシングは控えめにして、レモン汁やハーブで風味付けします。ボリュームたっぷりなのに約450kcalとヘルシーで、午後も胃がもたれず快適に過ごせました。

夕食のメニューは「鮭の塩焼きと温野菜、玄米ご飯」です。仕事から帰宅後、早速鮭をグリルで焼き、ブロッコリーやにんじんを茹でて温野菜にしました。玄米ご飯は普段白米を食べ慣れている私には少し噛み応えがありましたが、そのぶん少量でも満腹感があります。鮭の塩焼きはシンプルながら旨味たっぷりで大満足。1日目の食事管理はほぼ **ChatGPTの提案通り** 実践できました。

初日は新鮮なメニューばかりでしたが、お腹が空きすぎて困るということもなく、むしろ **バランスよく食べた充実感** がありました。この調子で明日も頑張ろうと、早めに就寝しました。

## 2日目: おやつが欲しい！AIに間食の提案をお願い

2日目の朝も、まずはChatGPTの提案どおりの朝食からスタートしました。ちなみにこの日の朝食メニューは「ほうれん草と豆腐の味噌汁、ゆで卵、りんご半分」という和風スタイル。たったこれだけ？と思いきや、温かい味噌汁で体が目覚め、タンパク質もしっかり摂れる内容です。

午前中は順調に過ごせました。昼には野菜たっぷりのチキンソテーと雑穀ご飯を美味しく平らげましたが、午後3時頃になると少し小腹が空いてきました。ChatGPTのプランではおやつの指示は特になかったのですが、ダイエット初心者の私は午後3時頃になるとどうしてもお菓子が恋しくなってしまいます。そこで無理をせず、素直に **AI栄養士に間食について相談** してみることにしました。

```
ダイエット中ですが、15時くらいに小腹が空いてしまいました。150kcal以内で満足感のあるおやつはありますか？
```

このプロンプトに対し、ChatGPTはすぐにいくつかの **ヘルシーなおやつ案** を提案してくれました。例えば、「無糖ヨーグルトにハチミツ少々とナッツを混ぜる」（約120kcal）や、「チーズ一本とゆで卵」（タンパク質豊富で約150kcal）、「小さいダークチョコレート1かけ」（高カカオで少量ならOK）などです。私はその中からヨーグルト+ナッツを選び、キッチンでぱぱっと用意しました。

実際に食べてみると、ほんのり甘くクリーミーで満足感があります。おやつを完全に我慢しなくても、 **選び方次第でダイエットの味方になる** と実感できました。ChatGPTに相談したおかげで罪悪感なく間食を楽しめ、気持ちをリセットして夕方以降も頑張れそうです。

その日の夕食は「野菜たっぷりの豆腐チャンプルーと雑穀ご飯」というメニューでした。ボリューム満点ながらカロリー控えめで、おやつを食べた後でも予定カロリー内に収まりました。2日目も大きな挫折なく終了。徐々に **ヘルシーな食生活** にも慣れてきた気がします。ダイエットに対する不安も薄れ、「これなら続けられそう！」と自信が芽生えてきました。

## 3日目: 体重に変化が！ChatGPTからの嬉しいアドバイス

ダイエット開始から3日目の朝。恐る恐る体重計に乗ってみると、 **59.5kg** と表示されました！スタートから0.5kg減です。まだ誤差の範囲かもしれませんが、確実に変化が出ていることに感激しました。わずか2日で効果が目に見えると、モチベーションが一気にアップします。

朝食にはChatGPT提案のグリーンスムージー（バナナ、ほうれん草、豆乳をミキサーにかけたもの）に初挑戦。見た目は緑色で少し驚きましたが、フルーツの甘みで思ったより飲みやすい！胃に優しく、栄養も満点です。昼食はサバの塩焼き定食（玄米ご飯とひじきの煮物付き）、夕食は豆腐ハンバーグと彩り野菜炒めといったメニューで、どれも美味しく頂きました。この3日間で **同じメニューは一度も出てきていません** 。毎日違う献立なので飽きることがなく、AI栄養士のレパートリーの広さに驚かされます。

特に夕食の豆腐ハンバーグは初めての料理でしたが、ChatGPTに簡単レシピを教えてもらいながら無事に作れました。

```
ヘルシーな豆腐ハンバーグの簡単なレシピを教えてください。
```

ChatGPTからは、豆腐ハンバーグを美味しく作るコツがいくつか提示されました。

- 木綿豆腐の水切りをしっかり行う（余分な水分を抜いて食感アップ）
- 野菜（玉ねぎや人参のみじん切り）や鶏ひき肉と混ぜて栄養&旨味アップ
- 焼くときは油を控えめにし、弱火でじっくり火を通す
- 焼き終えたら余分な油をキッチンペーパーで吸い取る

といったポイントを踏まえて調理開始。言われた通りに作ってみると、ふわふわでジューシーな豆腐ハンバーグが完成！ヘルシーなのに食べ応えがあり、大満足の一品になりました。

夕食後、ChatGPTに途中経過を報告してみることにしました。順調に減量できていることを伝え、今後も継続する上でのアドバイスをもらいます。

```
ダイエットを開始して3日で0.5kg減りました！この調子で続けるために、何かアドバイスや注意点はありますか？
```

ChatGPTからは「順調ですね、おめでとうございます！」と励ましの言葉が返ってきました。そして、今後も停滞期に焦らないこと、水分をしっかり摂ること、可能なら軽い運動も取り入れることなど、いくつかの丁寧なアドバイスをもらえました。その内容は次のようなものです。

- 焦らず継続しましょう
- 水分を十分に摂りましょう
- 可能なら軽い運動も取り入れてみましょう

まるで本物のトレーナーにコーチングされているようで、「よし、あと半分がんばろう！」とますますやる気が湧いてきました。

## 4日目: 中だるみを撃退！AI提案のヘルシーカレー

4日目になると、少し気の緩みが出てきました。順調とはいえ、毎日カロリー計算しながら食事を作る生活に少しだけ疲れが出始めます。加えて、ふと **大好物のカレーライス** が恋しくなってきました。スパイシーでコクのあるカレーを、ダイエット中は我慢しなきゃいけないの？と考えると少し憂鬱になります。このままではストレスでドカ食いしてしまうかも…という不安もよぎりました。

しかし、ここでも無理をせずChatGPTに頼ってみることにしました。食事管理を任せると言っても、我慢ばかりでは続きません。 **プロンプト** で正直に「カレーが食べたい！」と打ち明けて、ダイエット向きのレシピを尋ねてみます。

```
大好きなカレーライスが食べたい気分です。ダイエット中でも罪悪感の少ないカレーのレシピはありますか？
```

ChatGPTはすぐに **ヘルシーなカレーライスの作り方** を提案してくれました。ポイントは、油の量を控えめにして野菜をたっぷり使うこと。具体的には「玉ねぎや人参、ほうれん草など野菜をふんだんに入れ、鶏ささみや豆類でタンパク質を補給しましょう。ルーの代わりにカレー粉とコンソメ、トマト缶を使ってとろみを出すと低脂肪に仕上がります。ご飯は玄米を少なめによそい、カリフラワーライスを混ぜるとさらにカロリーオフできます」とのことでした。

教えてもらったとおりに野菜たっぷりのカレーに挑戦！トマトベースでさっぱりしていますが、スパイスのおかげで物足りなさは感じません。むしろ野菜の旨味が溶け込んで、普通のカレーよりも体に優しい味わいです。これなら約500kcal程度に抑えつつ、大好きなカレー欲も満たせました。

「ダイエット中でも工夫すればこんなに満足できるんだ！」と、目からウロコが落ちる思いです！！ChatGPTに相談したおかげで、中だるみしかけた気持ちをリフレッシュすることができました。好きなものを我慢しすぎずに済むのは、AI栄養士に任せる大きなメリットだと実感します。

## 5日目: 急な外食でも大丈夫？AI栄養士の賢いアドバイス

週も後半に差し掛かった5日目の朝。体重は **59.4kg** と3日目から大きな変化はありませんでしたが、ChatGPTから「停滞期も焦らないで」というアドバイスをもらっていたので不安はありません。順調に来ているし、体調も良好です。

そんな5日目、今度は **予期せぬ試練** が訪れました。仕事終わりに友人から食事に誘われたのです。ダイエット中とはいえ、付き合いも大切にしたい…そこでまたもやChatGPTに相談です。外食時のメニュー選びや注意点についてアドバイスを求めました。

```
今夜は友人と外食の予定があります。ダイエット中でも楽しめる外食のコツやメニュー選びを教えてください。
```

ChatGPTからは、外食時でも **賢く食べるコツ** がいくつも提示されました。例えば、ChatGPTからは次のようなポイントが提示されました。

- 最初にサラダやおひたしなど低カロリーな前菜を注文して満腹感を得る
- 揚げ物よりも焼き物や蒸し物を選ぶ
- クリーム系ソースではなくトマトソースの料理にする
- 飲み物はなるべくお水やお茶にする

具体的なメニュー例も挙げてくれたので、とても参考になりましたし、心強かったです。

その日の夜はファミリーレストランでの食事でしたが、私はChatGPTのアドバイスを思い出しながらメニューを選択。まずは野菜サラダを注文し、メインディッシュは照り焼きチキンのグリル（ご飯は少なめにしてもらいました）に決定。友人がおすすめしてくれたデザートも一口だけ味見して、あとはお茶を飲みながら楽しくおしゃべりをしました。

結果、外食を思いきり楽しみつつも、翌朝の体重増加はほとんどなし！むしろストレス発散になり、良い気分転換になりました。

ちなみに食事中、友人に「実は今ChatGPTに食事管理してもらっているんだ」と打ち明けると、「そんなことまでAIができるの！？」ととても驚かれました。AI栄養士のアイデアに興味津々で、会話が大いに盛り上がりました。私自身も改めてこの方法の面白さと可能性を実感した瞬間です。

**AI栄養士に相談しておいたおかげで、罪悪感なく外食を満喫** できたのは大きな収穫です。これならダイエット中でも友人との時間を諦めずに済むと自信がつきました。

## 6日目: 食事管理にも慣れて、見えてきた変化

6日目にもなると、AIに提案してもらった食事管理のリズムにもすっかり慣れてきました。朝・昼・晩とバランスよく食べることが当たり前になり、以前感じていたような過度な空腹感もほとんどありません。むしろ、 **体が軽く感じられ、目覚めも良くなった** 気がします。食生活を整えることで、こんなにも日常の調子が変わるとは驚きです。
