# chatGPTと壁打ち

## 🚃 行き（耳で前回の復習）

| 区間 | 活用方法 |
|------|----------|
| 徒歩10分 | 音楽やポッドキャストで気持ちを整える／太陽光を浴びて体を起こす |
| 地下鉄20分 | 耳学習（前回学習の復習音声：Kindle読み上げ／Voice Dream Reader／要点音声） |
| 電車30分 | 座れた時：公式テキストの復習を軽く読む（10分程度）<br>立っている時：耳学習の続き |
| 電車15分 | 今日の予定・タスク確認、軽いメール下書き |
| 徒歩10分 | 「今日最初にやること」を1つイメージしながら歩く |

## 🏠 帰り（問題演習がメイン）

| 区間     | 活用方法                                                |
| ------ | --------------------------------------------------- |
| 徒歩10分  | 音楽や雑談系ポッドキャストで気持ちを切り替える                             |
| 電車15分  | SNSチェック、友人への返信など軽めの時間                               |
| 電車30分  | 座れた時：公式テキストで問題演習・要点整理<br>立っている時：問題演習アプリや要点カード       |
| 地下鉄20分 | 前半10分：その日の問題演習を解き直し・耳で復習<br>後半10分：完全リラックス（漫画・音楽・動画） |
