# 走りの法則
## 01
# 「関節モーメント」の力こそがランニングエコノミーにつながる!

人間には、複雑な動きを可能にすると同時に、力を増幅する力学的なシステムが備わっています。関節モーメント(回転力、トルク)もそのひとつです。

関節モーメントとは、回転軸の回転力のことで、天秤で考えると、回転軸は中央の支点になります。回転軸から重りまでの距離(モーメントアーム)が長いほど、回転軸の回転力が大きくなりますが、左下の図のようにモーメントとモーメントアームの関係を理解することが重要です。

## 関節モーメントとはなにか?

関節モーメント=関節を回転させる力 (回転力・トルク)

モーメントは、力と距離の積で表されます。モーメント（M）は、力（N）に距離（m）をかけたものです。ここでいう力とは、加える力のことであり、距離とはモーメントアームのことです。

モーメントアームとは、回転軸の中心から力が加わる位置までの距離です。

また、関節モーメントにおける回転軸は関節であり、関節に対するモーメントアームが長いほど、回転力は強くなりますが、それだけ筋肉への負荷も高くなります。

また、関節モーメントは大きく分けて、外部関節モーメント(重力や床反力などの外力による関節の回転力)と、内部関節モーメント(筋肉や腱による関節の回転力)に分類されています。これらの仕組みを理解しておきましょう。

→左辺の重りを2kg、右辺のモーメントアームを2mにすると･････

## 天秤の釣り合い

天秤において、左辺に2kgの重りを1mの位置に置き、右辺に1kgの重りを2mの位置に置くと、左右のモーメントが釣り合い、天秤は水平を保ちます。左辺にかかる回転力は、2kg x 9.8m/s² x 1m = 19.6Nm であり、右辺にかかる回転力は、1kg x 9.8m/s² x 2m = 19.6Nm です。左右の回転力が等しいので、天秤は釣り合います。

モーメントアームが長いほど、少ない力でも関節の回転力(トルク)は大きくなる!

上の天秤のように、モーメントアームを左辺の2倍にすると、支点の回転力も2倍になるため、1/2の重りで釣り合うことができます。つまり、モーメントアームが長くなると、加える力が少なくても関節の回転力は大きくなるということ。
